# 方法

## 研究设计与研究人群

本研究基于UK Biobank（UKB）纵向肺功能资料，在基线非COPD人群（Healthy）和基线COPD人群中分别建立临床与遗传信息融合的预测模型，预测下一次随访肺功能及访视间快速下降风险。Healthy和COPD用于界定两个研究人群，而非模型的二分类结局。Healthy沿用原始数据流程中的基线非COPD定义，不等同于经额外筛选的严格正常肺功能人群。两个人群的模型独立拟合，不共享已训练的神经网络权重。

Healthy采用既定参与者级训练、验证和测试划分，原始分配人数分别为16,024、2,003和2,004。进一步要求目标可用且随访间隔为0.5–13年后，可用于临床基准建模的人数分别为15,169、1,895和1,918；在同时具有匹配基因型的样本中，神经融合模型的训练、验证和最终测试人数分别为15,015、1,877和1,899，六项任务人数一致。COPD模型使用2,067名具有可评估结局的参与者，采用参与者级留一交叉验证（leave-one-out cross-validation，LOOCV）生成折外预测。用于本次主图比较的Healthy测试样本与COPD样本经参与者标识核对不存在重叠。

本节对应两套UKB主模型及其比较，不将广东队列的模型适配、不同样本量的试验或额外临床token扩展混入同一训练流程。伦理审批、UKB申请编号、知情同意程序、基线COPD判定规则、肺功能检测及质量控制、原始基因型质量控制与基因组版本，须由原始研究资料补充，不能由模型代码反推。

## 预测目标与快速下降定义

设置六项监督学习任务，包括下一次实际随访的第一秒用力呼气容积（FEV₁）、用力肺活量（FVC）及FEV₁/FVC三个连续结局，以及相应的三项快速下降二分类结局。FEV₁和FVC以L表示，FEV₁/FVC使用绝对比值。记基线和下一次随访观测值分别为Y₀与Y₁，实际访视间隔为Δt（年），年化变化定义为：

ΔY_annual = (Y₁ − Y₀) / Δt。

FEV₁和FVC快速下降定义为ΔY_annual严格低于−0.060 L/年；FEV₁/FVC快速下降定义为年化比值变化严格低于−0.010/年。比值结局直接使用自身的纵向变化，不由两个分别年化的容量相除。三项分类任务直接使用上述事件标签训练，不通过阈值化连续结局的预测值生成。连续预测目标为下一次实际测量值，而非一年标准化的合成肺功能值。随访间隔作为预测输入，因此模型评估条件于给定预测时间跨度。

## 临床输入及预处理

Healthy模型使用16项临床输入：年龄、性别、体质指数、身高、吸烟包年、吸烟状态、基线FEV₁、基线FVC、基线FEV₁占预计值百分比、基线FEV₁/FVC、五项血细胞计数及随访间隔。五项血细胞指标对应UKB字段p30000_i0、p30120_i0、p30130_i0、p30140_i0和p30150_i0；最终论文中的生物学名称应与UKB字段字典逐项核对。临床变量采用训练数据中位数填补，保留缺失指示项，并进行标准化。神经分支的临床预处理管线在基因型匹配的训练子集中拟合。

COPD临床基准采用原有各任务特征集，并加入31个lead SNP剂量。其临床输入可包括年龄平方、身高平方等衍生项，不能等同于Healthy固定16字段。COPD复用原始临床估计器的特征定义和超参数模板，并在每个外层留一训练集中重新拟合管线与模型。类别展开及缺失处理沿用原保存管线。COPD临床基准还纳入PC1–PC10祖源主成分及原任务保留的血液、活动和呼吸相关字段。保存模型显示，三项连续任务Ridge的alpha均为0.1；区间FEV₁、FVC和比值快速下降logistic回归的C依次为0.1、0.01和0.1，solver为lbfgs、max_iter为3,000，不使用class_weight加权。完整字段与31个lead SNP需在补充表列示。

## 遗传输入及多基因风险评分

两套模型采用既定的4,064个遗传位点面板，不根据当前测试样本重新筛选位点。该面板来源于历史COPD关联分析，Healthy未利用自身预测结局重新开展位点筛选。按既定schema核对变异标识、基因型矩阵位置及等位基因方向；相反方向的剂量进行相应翻转。缺失剂量使用相应训练数据均值填补，并按训练均值和标准差标准化；对无有效变异的维度采用保护性缩放。

由同一剂量矩阵计算四项PRS，分别纳入历史关联P值≤10⁻⁵、10⁻⁴、10⁻³和0.01的位点。第k个评分为PRSᵢₖ = Σₘ βₘGᵢₘI(Pₘ≤τₖ)，其中Gᵢₘ为等位基因剂量，βₘ为既定关联权重。PRS在相应训练数据中标准化。四项评分具有重叠位点，且与直接基因型通道使用相同遗传来源，不视为彼此独立的遗传证据。Healthy的遗传预处理参数由其基因型匹配训练子集估计；COPD在每个外层留一折中排除被留出者后估计。

## 基因组Transformer编码与任务特异性汇聚

模型按染色体分组，沿既定schema顺序将每64个SNP组成一个patch，末端不足64个位点时补零。每个patch通过线性投影获得16维嵌入，并加入可学习的染色体嵌入和物理位置编码。位置特征由patch平均基因组位置除以10⁸及其正弦、余弦和log1p变换组成，再经线性层映射至16维。

SNP token输入单层Transformer编码器，使用两个注意力头、16维隐表示、32维前馈层、0.35的dropout及层归一化前置设置（norm_first=True）。编码层激活沿用TransformerEncoderLayer默认配置，任务输出MLP及Healthy临床MLP采用GELU。

四项PRS分别通过1→16线性投影并叠加可学习的PRS类型嵌入。PRS token在SNP self-attention编码完成后才与SNP token拼接，经层归一化后进入任务query注意力汇聚。对第j项任务，计算αᵢⱼₘ = softmaxₘ(qⱼᵀzᵢₘ/√16)，并得到hᵢⱼ = Σₘαᵢⱼₘzᵢₘ，其中qⱼ为可学习任务query，zᵢₘ为编码token。所得hᵢⱼ为16维任务表示。该模块是任务注意力池化，不是额外的完整Transformer层；注意力权重本身不用于证明特征重要性或因果机制。

## Healthy临床基准模型与联合残差学习

对三项连续任务分别建立Ridge回归，对三项事件任务分别建立logistic回归。Ridge正则化参数从{0.1,1,10,100}中选择，logistic回归的C从{0.001,0.01,0.1,1}中选择，分别以验证集MSE或log loss选择最优设置。临床基准模型使用满足任务条件的临床训练样本，不要求每名临床训练者均具有匹配基因型。训练集内采用三折交叉拟合生成临床折外预测，回归使用KFold，分类使用StratifiedKFold。

Healthy神经分支包含基因组编码器和临床MLP。变换后的临床向量通过“输入维度→32→16”网络映射，其间采用GELU及0.35 dropout。每项任务的16维基因组表示与16维临床表示拼接为32维向量，经“32→16→1”任务头产生神经修正量δᵢⱼ。任务头包含GELU及0.35 dropout，末层权重和偏置初始化为零。

连续任务使用训练集临床折外残差yᵢⱼ−bᵢⱼ^OOF，并以该训练子集残差标准差sⱼ缩放，保护下限对容量任务为0.01 L、对比值任务为0.001。分类任务使用临床折外概率的logit作为固定offset，以logit(bᵢⱼ^OOF)+δᵢⱼ计算BCE。概率在logit变换前截断至[10⁻⁵,1−10⁻⁵]。三项标准化残差MSE与三项offset BCE在各任务有效标签内取均值，再对有标签任务等权平均；缺失结局通过mask排除。

采用AdamW优化，学习率3×10⁻⁴，实际优化器权重衰减0.05，批量128，梯度范数上限0.5。随机种子为20261026。最多训练60轮，当验证损失连续10轮未达到至少10⁻⁴的改善时早停。保留验证损失最优状态，包括以零修正量初始化的起始状态。

在固定验证集中，分别为六项任务从wⱼ∈{0,0.1,0.25,0.5,1}选择融合权重，以连续任务MSE或分类log loss最小为准。最终连续预测为ŷᵢⱼ=bᵢⱼ+wⱼsⱼδᵢⱼ；分类风险为p̂ᵢⱼ=sigmoid[logit(bᵢⱼ)+wⱼδᵢⱼ]。测试集不参与模型参数、检查点或融合权重选择。若报告阈值相关指标，分类阈值由验证集候选概率分位点及0.5中选择，以平衡准确率最大为准；AUROC与AP计算不使用这一阈值。

## COPD参与者级留一与分离残差网络

在COPD人群中，每次留出一名参与者，以其余参与者重新拟合临床基准和神经修正网络。被留出者的所有结局不参与该折临床拟合、三折内部交叉拟合、归一化参数估计或梯度更新。临床特征与估计器超参数沿用固定历史模板，外层预测不用于重新选择模板。

每个外层训练集中生成三折临床折外预测。连续残差为rᵢⱼ=yᵢⱼ−bᵢⱼ^OOF，计算折内残差均值μⱼ与标准差sⱼ，并以(rᵢⱼ−μⱼ)/sⱼ为回归神经目标；标准差设置0.01的数值保护下限。分类网络以临床折外logit为offset，概率截断至[10⁻⁶,1−10⁻⁶]。

COPD的回归和分类网络分别拟合，每个网络各有三个任务query和三个任务输出头。输出头为“16→8→1”，使用GELU及0.35 dropout，末层零初始化。当前COPD神经分支只接收基因型和PRS，不含Healthy的临床MLP；临床信息通过独立基准预测进入最终融合。

回归网络最小化三项标准化残差的masked MSE。分类网络最小化offset BCE，并按训练集中第j项事件比例πⱼ的二元熵Hⱼ=max{0.05,−πⱼlogπⱼ−(1−πⱼ)log(1−πⱼ)}归一化对应任务损失，再对有效任务取平均。优化器为AdamW，学习率3×10⁻⁴、权重衰减0.03、批量128、梯度范数上限0.5，每个网络固定训练60轮，不以外层留出者的结果早停。

每个外层折分别以20261026与20261027两个种子训练，先对神经输出取均值δ̄ᵢⱼ，再进行融合。连续预测为ŷᵢⱼ=bᵢⱼ+μⱼ+sⱼδ̄ᵢⱼ；分类风险为p̂ᵢⱼ=sigmoid[logit(bᵢⱼ)+δ̄ᵢⱼ]，残差权重固定为1。阈值相关分类指标使用0.5阈值。汇总每名参与者被留出时的预测进行评价，最终每人每任务仅贡献一个折外预测。

## 性能评价及置信区间

连续结局报告Pearson相关系数、Spearman秩相关系数、决定系数R²及RMSE。R²按1−Σᵢ(yᵢ−ŷᵢ)²/Σᵢ(yᵢ−ȳ)²计算，不以Pearson相关系数平方替代。容量RMSE以L表示，比值RMSE无量纲，不跨单位直接比较误差大小。

分类结局报告AUROC及average precision（AP，图中标记为AUPRC）。AP按预测阈值变化所产生的召回率增量加权precision计算，不以梯形积分结果替代。每项任务同时报告总人数、事件数及事件比例，并结合事件比例解释PR表现。Healthy与COPD的快速FEV₁下降事件分别为402/1,899和443/2,067，快速FVC下降为560/1,899和890/2,067，比值快速下降为77/1,899和63/2,067。

对保存的个体预测实施2,000次参与者有放回bootstrap，取第2.5和97.5百分位作为各性能指标的95%区间。分类抽样不固定事件比例；若某次样本仅包含单一类别，则跳过该次不适用指标计算并记录有效次数。ROC和PR曲线另采用500次参与者bootstrap，在共同横坐标网格上插值，计算逐点95%区间。上述区间条件于固定模型、特征面板及现有预测，不包括重新训练与上游筛选方差；逐点区间不是全曲线同时置信带，也未完整覆盖LOOCV折间共享训练样本的依赖。

## 临床贡献及直接遗传通道归因

解释性分析的主要目标为下一次FEV₁预测。Healthy临床贡献由仿射临床基准的精确线性分解与神经分支临床输入的Integrated Gradients（IG）相加构成；与原字段对应的缺失指示贡献先按个体有符号合并，再计算平均绝对值。COPD临床贡献来自各留一折仿射临床分支，相对于相应训练背景进行精确分解，并将展开类别及缺失项映射回原始输入。各组按平均绝对贡献分别选取Top 10。两组该部分归因覆盖范围不同，不将条长差异作为正式组间机制检验。

遗传面板分别展示直接SNP剂量通道IG的Top 10，归因单位转换为mL；该口径不包含PRS路径及COPD临床分支lead SNP路径。数值计算沿输入参考至观测输入的路径积分，并核对归因加和误差。对COPD完整遗传归因的补充分析，可按链式法则将PRS路径贡献重新分配回原位点，并与直接剂量及临床SNP贡献按变异合并；合并后不再额外叠加PRS总贡献。直接通道排序和全路径排序是不同口径，不混用为同一结果。IG、仿射贡献和注意力均不解释为因果效应。

## 共享与疾病状态相关预测依赖的探索性分析

以两组下一次FEV₁原生模型为对象，预先按五个概念分组开展置换：基线肺功能、随访间隔、年龄、吸烟及全部遗传/PRS。基线肺功能块联合替换FEV₁、FVC、FEV₁预计值百分比和FEV₁/FVC；年龄及吸烟块包含各原模型中的相应衍生项。遗传块对同一供者的直接剂量及同源PRS同步替换，COPD同时替换临床31个SNP。PRS与原剂量保持同源，不把重叠路径重复计数。

每组使用10个一对一且无自供者的随机错排，在原始留出模型下重新预测。置换重要性定义为10次置换RMSE的均值减原始RMSE，正值表示该组信息被扰动后性能下降，零或负值均按原值保留。对参与者重复bootstrap 2,000次，同一次重抽样中各特征块使用相同索引，形成固定模型及供者映射下的条件95%区间。

补充表计算ΔI=I_COPD−I_Healthy及其条件百分位区间；两组分别独立重抽样。双侧近似P值基于以原始估计为中心的bootstrap误差绝对值与原差值比较，采用加1修正，并对五项检验作Benjamini–Hochberg校正。此分析检验原生模型的预测依赖差异，不消除人群组成、原生特征定义、模型结构或评价设计差异；未将其作为统一模型下的疾病特异性证明。

## 可重复性与解释边界

分析基于Python、NumPy、pandas、scikit-learn及PyTorch实现，保存个体预测、参与者划分、模型权重、预处理参数、任务选择配置及归因数据。Healthy训练种子为20261026，COPD神经模型种子为20261026和20261027；本次比较图的bootstrap种子为20261028。最终论文应从原运行环境导出准确的软件版本和依赖文件。

模型评估须条件于历史固定的遗传面板和既往探索的架构、临床模板。COPD上游遗传发现与预测队列存在样本重叠，外层LOOCV未重新嵌套GWAS或全部特征选择，因此不能宣称独立遗传发现验证。Healthy固定测试与COPD LOOCV的性能只作描述性并列；预测依赖和IG差异不直接证明疾病特异性生物机制。统一特征重拟合、统一外层评估、条件置换及包含训练重拟合的bootstrap是后续验证方案，尚未完成，不写为已实施方法。
